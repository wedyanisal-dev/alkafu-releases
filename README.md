# Alkafu OS — Official OTA Distribution Endpoint

This repository serves exclusively as the public Over-The-Air (OTA) distribution and update verification feed for **Alkafu OS** (running on GAC GS8 / Trumpchi A60 platforms).

> [!NOTE]
> The source code for Alkafu OS is maintained in a private repository: [`wedyanisal-dev/alkafu-os`](https://github.com/wedyanisal-dev/alkafu-os).
> This repository contains zero source files and hosts only compiled, cryptographically-signed releases and update metadata (`version.json`).

### Release Feeds
- **Latest Version Metadata:** [releases/latest/download/version.json](https://github.com/wedyanisal-dev/alkafu-releases/releases/latest/download/version.json)
- **Official Releases:** [GitHub Releases](https://github.com/wedyanisal-dev/alkafu-releases/releases)
